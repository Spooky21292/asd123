# Quotes Vault

Готовый статический сайт-хранилище мотивационных цитат на русском языке.

## Возможности

- 30 коротких цитат (Философия / Психология / Бизнес)
- Переключение: предыдущая, следующая, случайная
- Фильтр по категориям + отдельный фильтр «Избранное»
- Поиск по тексту, автору и тегам
- Копирование цитаты в буфер обмена (Clipboard API)
- «Цитата дня» (стабильная в течение суток на основе локальной даты)
- Избранное с сохранением в `localStorage`
- Тёмный минималистичный UI, адаптивность, мягкие анимации
- Поддержка `prefers-reduced-motion`

## Локальный запуск

1. Скачайте проект.
2. Откройте файл `index.html` двойным кликом в браузере.

Никакой сервер или сборка не требуется.

## Деплой

### GitHub Pages

1. Залейте проект в репозиторий GitHub.
2. Откройте **Settings → Pages**.
3. В Source выберите ветку (`main`) и корень (`/root`).
4. Сохраните — получите публичный URL.

### Netlify

1. Создайте сайт через **Add new site → Deploy manually**.
2. Перетащите папку проекта целиком.
3. Публикация будет выполнена автоматически.

### Vercel

1. Импортируйте репозиторий в Vercel.
2. Для статического проекта настройки по умолчанию подойдут.
3. Нажмите Deploy.
